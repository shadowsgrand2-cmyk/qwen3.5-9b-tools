# Qwen3.5-9B Tools

Инструменты и конфиги для локальной модели **Qwen3.5-9B** на RTX 3060 12GB.

## Быстрый старт

### 1. Модель уже импортирована в Ollama

```bash
ollama run qwen3.5-9b
```

### 2. Open WebUI (удобный чат в браузере)

```bash
pip install open-webui
open-webui serve
```

Открой: http://localhost:8080

## Полезные инструменты

- **Open WebUI** — лучший веб-интерфейс для Ollama
- **AnythingLLM** — RAG + агенты
- **Continue.dev** — плагин для VS Code / JetBrains
- **SillyTavern** — для ролевых игр и персонажей
- **llama.cpp** — низкоуровневый контроль
